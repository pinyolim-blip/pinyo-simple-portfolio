# Pinyo Limphongsathorn - Data Analyst Portfolio

A modern, professional portfolio website designed for a Data Analyst. Built with a focus on clean aesthetics, technical precision, and user experience.

## 🌟 Features

- **Modern Dark Theme:** A sleek, developer-centric default theme using JetBrains Mono typography.
- **Theme Toggle:** A smooth sun/moon icon toggle to switch between dark and light modes with persistence (remembers your choice).
- **Responsive Design:** Optimized for all screen sizes, from mobile phones to high-resolution monitors.
- **Project Showcase:** Highlights key data analysis projects including insurance claims analysis and predictive modeling.
- **Interactive Elements:** Subtle fade-in animations and smooth scrolling.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for optimal SEO and accessibility.
- **CSS3:** Custom properties (variables) for theme management and flexbox/grid layouts.
- **JavaScript (Vanilla):** Lightweight interactivity and theme persistence using `localStorage`.
- **Typography:** [JetBrains Mono](https://www.jetbrains.com/lp/mono/) via Google Fonts.

## 🚀 Deployment

This site is designed to be hosted on **GitHub Pages**.

1. Fork or clone this repository.
2. Go to repository **Settings > Pages**.
3. Set the **Source** to "Deploy from a branch".
4. Select the `main` branch and `/ (root)` folder.
5. Click **Save**.
